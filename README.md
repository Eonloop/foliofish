# My portfolio

This repo is my personal portfolio site utilizing the [Hugo](https://gohugo.io/) framework with the [Blowfish](https://github.com/nunocoracao/blowfish) theme. 

### Sections
- About
- Blog
- Resume
- Projects 
- Contact Me

This site is a constant work in progress, but it felt like the right place to keep a profile about myself. 

You can fill out a form to contact me from the website, or my contact information can also be found on my resume which you can download in the "Resume" section of the website. 

Additionally you will find links to my GitHub and LinkedIn accounts as well. 

Thank you for taking the time to take a look, and please feel free to submit feedback in the "Contact Me" section as well. I'm always looking for constructive criticism and advice.
